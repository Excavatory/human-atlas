# Атлас человека

Интерактивный 3D-исследователь анатомии на React, Three.js и shadcn/ui. Разберите эталонную анатомию взрослого мужчины BodyParts3D на **2234 индивидуально выбираемых меша**, изучите **15 анатомических систем** и ищите среди **3432 именованных концептов**.

**[Открыть демо](https://human-atlas-seven.vercel.app)**

> **Язык интерфейса.** Интерфейс по умолчанию на русском, с переключателем RU | EN. Имена анатомических концептов и мешей из `atlas.json` (BodyParts3D) пока остаются на английском — поиск работает по английским названиям.

## Возможности

- Вращайте, масштабируйте и выбирайте структуры прямо на модели.
- Включайте отдельные системы или пресеты «Скелет» и «Органы».
- Переходите от собранной анатомии к разнесённому инвентарю всех видимых частей.
- Ищите анатомические имена и идентификаторы источника (на английском).
- Изолируйте выбранную структуру и читайте пояснения на языке интерфейса.

## Запуск локально

```sh
npm ci
npm run dev
```

Откройте http://localhost:3016.

## Локализация

- Кастомный модуль `lib/i18n.tsx` (LocaleProvider, `useT` / `useLocale`) без тяжёлых npm-зависимостей.
- Локаль хранится в `localStorage` (`human-atlas-locale`), по умолчанию `ru`.
- Переводятся UI, названия и описания систем, пояснения (EXPLANATIONS), тексты загрузки/ошибок и лист «Об атласе».
- Имена структур из BodyParts3D остаются на английском.
